# Simulated Contact-Field Data

Simulated data can be downloaded from Hugging Face or collected locally. Local collection has two stages:

1. IsaacGym/TacSL collects scripted rollouts and tactile/pose/point-cloud observations.
2. PyBullet replays each rollout and writes contact pseudo-labels as a sibling `*_contact.pkl` file.

Each rollout should look like:

```text
data/sim/tools/train/scraper_8_train_0.pkl
data/sim/tools/train/scraper_8_train_0_contact.pkl
data/sim/tools/test/scraper_8_test_0.pkl
data/sim/tools/test/scraper_8_test_0_contact.pkl
```

## Download Sim Data

Simulated contact-field data is hosted in the SCFields Hugging Face Dataset repository:

```bash
conda activate scfields-policy
hf download Kevinskwk/scfields-release \
  --repo-type dataset \
  --include "data/sim/**" \
  --local-dir $SCFIELDS_ROOT
```

Downloaded layout:

```text
data/sim/tools/train/*.pkl
data/sim/tools/test/*.pkl
data/sim/tools/val/*.pkl
data/sim/peelers/train/*.pkl
data/sim/peelers/test/*.pkl
data/sim/peelers/val/*.pkl
```

## Collect One Object

Install Isaac Gym separately, then run from the repo root:

```bash
conda activate scfields-isaacgym
pip install -e $SCFIELDS_ROOT/isaacgymenvs

SIM_DEVICE=cuda:0 \
GRAPHICS_DEVICE_ID=0 \
SPLIT=train \
RUN_ID=0 \
NUM_ENVS=8 \
MAX_STEPS=200 \
bash scripts/collect_contact_field_data.sh scraper_8
```

Use `SPLIT=test RUN_ID=0` for held-out rollouts. The wrapper runs IsaacGym first and PyBullet contact labeling second.

## Collect Many Objects

```bash
bash scripts/collect_contact_field_data_parallel.sh \
  --devices "cuda:0 cuda:1 cuda:2 cuda:3" \
  --geometry-names "scraper" \
  --geometry-ids "1-25" \
  --split train \
  --iterations 1 \
  --num-envs 8 \
  --max-steps 200 \
  --graphics-device-id 0
```

Use `--subassemblies "scraper_8 cylinder_1"` to bypass geometry-name/id expansion. Logs and `summary.tsv` are written under `logs/contact_field_data/<timestamp>/`.

## Manual Stages

IsaacGym rollout:

```bash
cd $SCFIELDS_ROOT/isaacgymenvs
python collect_data.py \
  --config-name=data_collection \
  output_dir=$DATA_ROOT/sim/tools \
  task.env.asset_info_filename=tacsl_asset_info_generated_tools.yaml \
  task.env.subassembly=scraper_8 \
  split=train \
  id=0 \
  num_envs=8 \
  max_collection_steps=200 \
  sim_device=cuda:0 \
  rl_device=cuda:0 \
  graphics_device_id=0
```

PyBullet labels:

```bash
python pybullet_contact_collection.py \
  --config-name=pybullet_contact_collection \
  data_path=$DATA_ROOT/sim/tools/train/scraper_8_train_0.pkl \
  task.env.asset_info_filename=tacsl_asset_info_generated_tools.yaml \
  task.env.subassembly=scraper_8
```

`data_path` can also be a directory; every non-contact `*.pkl` file in that directory is processed.

## Notes

- `assets/tacsl/yaml/tacsl_asset_info_generated_tools.yaml` is generated by `assets/generate_tools.py` when regenerating tool assets locally.
- Keep `--graphics-device-id 0` unless your IsaacGym installation is configured for camera interop on a different graphics device.
- Simulated RGB camera frames for visualization are disabled by default. For test visualization, uncomment `front` / `front_depth` entries in `isaacgymenvs/cfg/task/TacSLDataCollectionTool.yaml` under `task.env.obsDims`.
- Some IsaacGym builds exit with code `139` after saving. The wrapper continues only if the expected rollout file exists.

# Combined Peeler Assets

Generated combined peeler meshes, raw peeler component meshes, URDFs, and
metadata are not stored in this repository. Download the release assets from
Hugging Face so this directory contains:

```text
assets/peelers_combined/mesh/
assets/peelers_combined/urdf/
assets/peelers_combined/yaml/tool_asset_info_peelers.yaml
assets/peelers_combined/raw/peeler_heads/*.obj
assets/peelers_combined/raw/peeler_handles/*.obj
assets/tacsl/yaml/tacsl_asset_info_peeler_combined.yaml
```

The generation scripts remain under `assets/peelers_combined/`.

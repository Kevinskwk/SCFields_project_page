# Raw Peeler Components

Raw peeler head/handle meshes are not stored in git. They are part of the
SCFields Hugging Face artifact repository.

After downloading assets, this directory should contain:

```text
assets/peelers_combined/raw/peeler_heads/*.obj
assets/peelers_combined/raw/peeler_heads/*.mtl
assets/peelers_combined/raw/peeler_handles/*.obj
assets/peelers_combined/raw/peeler_handles/*.mtl
```

These raw components are required only if you want to regenerate combined
peeler meshes with `combine_peelers.py`.

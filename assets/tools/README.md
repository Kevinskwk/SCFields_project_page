# Tool Assets

Generated tool meshes, URDFs, and metadata are not stored in this repository.
Download the release assets from Hugging Face so this directory contains:

```text
assets/tools/mesh/
assets/tools/urdf/
assets/tools/yaml/tool_asset_info.yaml
assets/tacsl/yaml/tacsl_asset_info_generated_tools.yaml
```

Download command:

```bash
bash scripts/download_assets.sh
```
